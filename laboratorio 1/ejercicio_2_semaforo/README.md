# Ejercicio 2: Semaforo vehicular

## Objetivo

Simular un semaforo vehicular usando tres salidas digitales.

## Componentes y conexiones

- LED rojo en el pin 13.
- LED amarillo en el pin 12.
- LED verde en el pin 11.
- Resistencias adecuadas para cada LED.

## Funcionamiento

El ciclo muestra las siguientes senales:

1. Rojo durante 5 segundos.
2. Verde durante 5 segundos.
3. Amarillo durante 2 segundos.

El ciclo se repite continuamente. El codigo se encuentra en `ejercicio_2_semaforo.ino`.
