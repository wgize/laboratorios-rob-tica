# Ejercicio 1: LED parpadeante

## Objetivo

Controlar una salida digital para encender y apagar un LED en intervalos de un segundo.

## Componentes y conexion

- Arduino UNO o placa compatible.
- LED conectado al pin digital 13.
- Resistencia para el LED si se usa un LED externo.

## Funcionamiento

El LED permanece encendido durante un segundo y apagado durante otro segundo. El ciclo se repite continuamente.

El codigo se encuentra en `ejercicio_1_led_parpadeante.ino`.
